# 07. PWA 화면 시안

Type: prototype
Status: → GitHub Issue #7 (상태·라벨은 거기가 정본이다)
Blocked by: 05

## Question

매일 아침 실제로 보게 될 화면을 **만들어서 보고 판단한다.** 말로 정하면 안 되는 종류의 결정이다.

만들 것: 가짜 데이터를 넣은 아이폰 폭 한 장짜리 HTML. 실제로 아이폰에서 열어보고 반응을 받는다.

판단할 것:

- 다섯 섹션을 한 화면에 다 펼치는가, 접어두는가, 탭으로 나누는가
- 스크롤 없이 보이는 첫 화면에 무엇이 오는가 (브리핑 3줄? Top5? 오늘의 키워드?)
- 항목 하나가 차지하는 높이 — 제목만인가, 한 줄 요약까지 보이는가
- 링크를 탭하면 어디로 가는가 (사파리 새 탭? 앱 안에서?)
- 설정(시각·알림·섹션 on/off) 진입점은 어디인가
- 어제 것을 보여줄 때 스테일 배지가 어떻게 보이는가
- 다크 모드

`prototype` 스킬을 호출할 것. 결과물은 버리는 물건이다 — 예쁘게 만들지 말고 빨리 보여줄 것.

**`DESIGN.md`(리포 루트)를 그대로 따른다.** Apple (España) 스타일 레퍼런스이고, refero.design의 자체 생성기로 뽑아 원문 그대로 커밋했다.
시안은 이 문서의 토큰 안에서만 그린다 — 색·라운드·타이포를 새로 만들지 않는다.

특히 구속력 있는 것:

- 본문 17px 단일 크기, 헤드라인은 SF Pro Display 600
- `#f5f5f7` 캔버스 / `#ffffff` 카드 / `#1d1d1f` 텍스트 / 주요 액션 하나만 `#0071e3`
- 카드 28px, 버튼은 980px 풀 필. 그 외 반경은 10/28/32/36만
- **그림자 금지.** 깊이는 표면 대비와 1px 헤어라인으로만
- 좌측 정렬. 헤드라인·액션을 가운데 두지 않는다

**이 티켓이 풀어야 할 충돌**: DESIGN.md는 **라이트 테마 전용**이고 다크 팔레트를 정의하지 않는다.
아침에 보는 보드라 다크 모드가 필요한지, 필요하다면 시스템 밖의 색을 지어내지 않고 어떻게 할 것인지를 여기서 정한다.

또 하나: [04](04-notification-channel.md) 결과로 **알림 시각은 앱이 아니라 아이폰 단축어에 산다.**
설정 화면에 시각 선택기를 넣을 이유가 사라졌다 — 설정에 뭐가 남는지 다시 볼 것.

## Answer

> **에이전트가 대신 결정함** (2026-09-20 야간 자율 세션). 사용자가 시안을 직접 보기 전의 잠정 결정이고,
> 아래 "되돌리려면" 항목대로 한 줄씩 뒤집을 수 있다.

시안: `prototype/board-preview.html` — 폰에서 열어볼 링크 https://claude.ai/artifact/HfdswiX5pGcTbkLd8cVTNF
상단 버튼으로 **정상 / 일부 실패 / 스테일 / 다크** 네 상태를 전환해 볼 수 있다.

### 결정한 것

| 질문 | 결정 | 이유 |
|---|---|---|
| 4개 섹션을 어떻게 놓나 | **세로로 전부 펼침** + 상단에 섹션 바로가기 알약 | 탭으로 나누면 "오늘 전체가 어땠나"를 한 번에 못 본다. 20개면 스크롤이 감당된다 |
| 첫 화면에 뭐가 오나 | 날짜 → 제목 → 상태 칩 → 바로가기 → **첫 섹션 브리핑** | 브리핑이 첫 화면에 들어오는 게 핵심. 스크롤 없이 "오늘 뭐 있었나"가 읽힌다 |
| 카드 한 칸 | 변화 배지 → 원문 제목 → 한국어 요약 → 헤어라인 → 출처·화제도 | 05에서 정한 계약 그대로. 제목은 21px, 요약은 본문 17px |
| 출처 표시 | **"출처 5곳"을 먼저**, 매체 이름은 그 뒤 | 화제도의 주 신호가 출처 개수라는 사실을 화면이 그대로 드러낸다 |
| 링크 | 제목 전체가 링크 | 탭 영역이 넓어야 한다 |
| 설정 진입점 | 맨 아래 파란 알약 버튼 하나 | 하루 한 번 보는 화면에 설정이 위에 있을 이유가 없다 |
| 스테일 표시 | 날짜 줄이 어제로 바뀌고 **주황 칩**으로 "오늘 보드가 아직 없습니다" | 오류 화면 대신 어제 것을 보여주되, 언제 것인지 숨기지 않는다 |
| 빈 섹션 | 섹션은 남기고 카드 자리에 **이유 한 줄** | 05에서 정한 원칙의 화면판 |

### 다크 모드 충돌 — 이렇게 풀었다

`DESIGN.md`는 라이트 전용이고 다크 팔레트가 없다. **새 색을 지어내지 않고 시스템 안의 색으로 역할만 뒤집었다.**

| 역할 | 라이트 | 다크 |
|---|---|---|
| 바탕 | Pure Canvas `#f5f5f7` | **Void `#000000`** |
| 카드 | Paper White `#ffffff` | **Obsidian `#1d1d1f`** |
| 글자 | Obsidian `#1d1d1f` | **Pure Canvas `#f5f5f7`** |
| 액션 | Signal Blue `#0071e3` | 그대로 |

전부 `DESIGN.md`에 이미 정의된 토큰이다. Apple 제품 페이지가 실제로 쓰는 검은 밴드 조합이라 시스템 밖으로 나가지 않는다.
**팔레트를 늘리지 않고 다크를 얻었으므로, 디자인 시스템을 따른다는 약속이 깨지지 않는다.**

### 05에서 넘어온 것 정리

**설정 화면에 시각 선택기를 넣지 않았다.** 04에서 알림 시각이 아이폰 단축어로 빠졌기 때문이다.
설정에 남는 것은 **섹션 표시 여부** 정도이고, 그래서 버튼 하나로 충분하다.

### 되돌리려면

- 섹션이 길다고 느껴지면 → 섹션당 5개를 3개로. 05의 분량 결정을 바꾸는 일이라 05도 같이 고쳐야 한다
- 탭 방식을 원하면 → 바로가기 알약을 탭 바로 바꾸면 되고, 카드 구조는 그대로다
- 다크가 너무 검으면 → 바탕을 Void `#000000` 대신 Obsidian `#1d1d1f`으로 한 단계 올린다. 여전히 시스템 안이다
- 화제도 숫자가 군더더기면 → 메타 줄에서 빼면 된다. 출처 개수만 남겨도 의미는 산다
