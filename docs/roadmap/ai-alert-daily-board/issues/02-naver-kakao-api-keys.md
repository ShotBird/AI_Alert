# 02. 네이버·카카오 검색 API 키 발급

Type: task
Status: open
Blocked by: (없음)

## Question

커뮤니티 섹션의 한국어 신호는 네이버·카카오의 공식 검색 API에 의존한다. 둘 다 무료지만
**사람이 직접 개발자 등록을 해야** 키가 나온다. 에이전트가 대신할 수 없는 작업이다.

필요한 것:

- 네이버 개발자센터 애플리케이션 등록 → **검색 API**(블로그/카페글/뉴스) 사용 신청 → Client ID / Client Secret 확보
  - 하루 25,000건 무료로 알려져 있으나, 2026년 6월 NAVER API HUB 이관 중이라 **실제 할당량을 발급 화면에서 확인**할 것
- 카카오 developers 애플리케이션 등록 → **다음 검색 API** 활성화 → REST API 키 확보
- (선택) 네이버 데이터랩 검색어 트렌드 API — "오늘의 키워드"에 국내 검색량 추이를 붙이는 용도

해결 조건: 키 두 개(+선택 하나)가 발급되고, `.env`에 저장되고, `.gitignore`가 그 파일을 막고 있는 것이 확인됨.
답변에는 **발급된 실제 할당량 숫자**를 적을 것 — 파이프라인 호출 빈도 설계가 여기에 걸린다.

키 값 자체는 이 파일에 절대 적지 않는다.

## 체크리스트 (2026-09-20 수정 — 네이버 경로가 바뀌었음)

**정정**: 처음 쓴 체크리스트는 틀렸습니다. `developers.naver.com`의 "사용 API" 목록에 **검색이 없습니다**.
목록에 남은 건 로그인·인증서·전자문서·배송지정보·카페·캘린더·캡차 뿐 — 전부 사용자 동의가 필요한 API입니다.
확인 결과 **검색 API는 NAVER API HUB로 이관**됐고, 이 허브는 **네이버 클라우드 플랫폼(ncloud.com)에서 운영**됩니다.
네이버 공식 문서(`developers.naver.com/products/service-api/search/search.md`)에도 "NAVER API Hub 이용신청" 버튼만 남아 있고
링크는 `https://www.ncloud.com/product/applicationService/naverApiHub`를 가리킵니다.

### 1. 네이버 — API HUB 경유

1. `https://www.ncloud.com/product/applicationService/naverApiHub` 접속 → **신청하기**
2. 네이버 클라우드 플랫폼 계정이 필요합니다 (네이버 아이디와 별개). 없으면 회원가입
3. 콘솔에서 **NAVER API HUB** → 사용할 API로 **검색 API** 선택
   - 오늘의 키워드에 국내 검색량 추이를 붙이려면 **검색어 트렌드**도 같이 선택
   - 허브는 **키 하나로 여러 네이버 API를 쓰는 구조**라 API별 개별 신청이 없습니다
4. 발급된 키를 `.env`에 저장

**확인된 요금 (한국 리전, 공식 요금표):**

| API | 무료 구간 | 요금 | 비고 |
|---|---|---|---|
| **검색 API** | 0 ~ 775,000건 | **0원** | **일 최대 25,000건** 호출 제한 |
| 검색어 트렌드 | 0 ~ 30,000건 | 0원 | 30,001~50,000건은 한시적 무료 |
| 쇼핑 인사이트 | 0 ~ 30,000건 | 0원 | 이 프로젝트에선 불필요 |

→ **우리 사용량에는 압도적으로 넉넉합니다.** 하루 키워드 8개를 조회해도 월 240건 수준이라
검색어 트렌드 무료 구간(월 30,000건)의 1%도 안 씁니다.
단 공식 문구에 **"한시적 무료 제공 정책은 추후 변경될 수 있습니다"**가 붙어 있으니, 무료가 영구 보장은 아닙니다.

⚠️ **확인 못 한 것 하나**: NCP 가입에 **결제수단(카드) 등록이 필요한지**를 공개 페이지에서 확인하지 못했습니다.
무료 구간이라 청구는 0원이지만, 가입 절차에서 카드를 요구할 수 있습니다.
**요구하면 진행하지 말고 알려주세요** — 개인 취미 프로젝트에 카드를 물릴 가치가 있는지는 별개 판단이고,
카카오 + GeekNews + Hacker News만으로도 커뮤니티 섹션은 성립합니다.

### 2. 카카오 — 경로 변화 없음

1. `developers.kakao.com` → 카카오 계정 로그인
2. **내 애플리케이션 → 애플리케이션 추가하기** (앱 이름 `AI Alert`)
3. **앱 키** 화면에서 **REST API 키** 복사 → `.env`에 저장
4. 다음 검색 API가 이 키로 실제 호출되는지는 키를 받은 뒤 에이전트가 확인

### 3. 키 저장

리포 루트 `.env.example`을 복사해 `.env`로 이름을 바꾸고 값을 채웁니다.
`.gitignore`가 `.env`를 막고 있어 키가 git에 올라가지 않습니다 (확인 완료).
키 값 자체는 이 티켓 파일에 적지 마세요.

### 해결 조건

- [ ] NCP 가입이 카드를 요구하는지 확인 → 요구하면 여기서 멈추고 보고
- [ ] `.env`에 네이버 API HUB 키, `KAKAO_REST_API_KEY` 채워짐
- [ ] 두 API가 실제로 응답하는지 호출 확인 (에이전트가 수행)
