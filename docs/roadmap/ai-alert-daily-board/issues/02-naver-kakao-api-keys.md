# 02. 네이버·카카오 검색 API 키 발급

Type: task
Status: open
Blocked by: (없음)

## Question

커뮤니티 섹션의 한국어 신호는 네이버·카카오의 공식 검색 API에 의존한다. 둘 다 무료지만
**사람이 직접 개발자 등록을 해야** 키가 나온다. 에이전트가 대신할 수 없는 작업이다.

필요한 것:

- 네이버 개발자센터 애플리케이션 등록 → **검색 API**(블로그/카페글/뉴스) 사용 신청 → Client ID / Client Secret 확보
  - 하루 25,000건 무료로 알려져 있으나, 2026년 6월 NAVER API HUB 이관 중이라 **실제 할당량을 발급 화면에서 확인**할 것
- 카카오 developers 애플리케이션 등록 → **다음 검색 API** 활성화 → REST API 키 확보
- (선택) 네이버 데이터랩 검색어 트렌드 API — "오늘의 키워드"에 국내 검색량 추이를 붙이는 용도

해결 조건: 키 두 개(+선택 하나)가 발급되고, `.env`에 저장되고, `.gitignore`가 그 파일을 막고 있는 것이 확인됨.
답변에는 **발급된 실제 할당량 숫자**를 적을 것 — 파이프라인 호출 빈도 설계가 여기에 걸린다.

키 값 자체는 이 파일에 절대 적지 않는다.

## 체크리스트 (2026-09-20 준비)

메뉴 이름은 사이트 개편으로 조금씩 달라질 수 있습니다. **찾아야 할 것**을 기준으로 적었습니다.

### 1. 네이버 — 약 5분

1. `developers.naver.com` 접속 → 네이버 계정으로 로그인
2. 상단 **Application → 애플리케이션 등록**
3. 애플리케이션 이름: `AI Alert` (아무거나 됩니다)
4. **사용 API에서 `검색`을 반드시 체크** — 이걸 빼면 키는 나와도 검색 호출이 막힙니다
   - 오늘의 키워드에 국내 검색량 추이를 붙이고 싶으면 **`데이터랩 (검색어 트렌드)`도 같이 체크**
5. "비로그인 오픈 API 서비스 환경"을 물어보면 **WEB 설정**을 고르고 URL에 `http://localhost` 입력
   (개인용이라 실제로 안 쓰는 주소여도 됩니다)
6. 등록하면 **Client ID**와 **Client Secret**이 나옵니다 → `.env`에 저장
7. **내 애플리케이션 → API 설정**에서 **일일 허용량 숫자를 확인해 아래에 적어주세요.**
   흔히 25,000건으로 알려져 있지만 네이버가 API HUB로 이관 중이라 실제 값이 다를 수 있습니다.
   이 숫자에 따라 하루에 몇 개 키워드를 조회할지가 정해집니다.

### 2. 카카오 — 약 3분

1. `developers.kakao.com` 접속 → 카카오 계정으로 로그인
2. **내 애플리케이션 → 애플리케이션 추가하기** (앱 이름 `AI Alert`, 회사명은 아무거나)
3. 만들어진 앱 → **앱 키** 화면에서 **REST API 키** 복사 → `.env`에 저장
4. 다음 검색 API는 별도 신청 없이 이 키로 호출되는 것으로 알려져 있습니다.
   **실제로 한 번 호출해보고 되는지 확인이 필요합니다** — 이건 제가 키를 받은 뒤에 하겠습니다.
5. 쿼터 표시가 있으면 숫자를 아래에 적어주세요.

### 3. 키 저장

리포 루트의 `.env.example`을 복사해 `.env`로 이름을 바꾸고 값을 채우면 됩니다.
`.gitignore`가 `.env`를 막고 있어 **키가 git에 올라가지 않습니다** (확인 완료).
키 값 자체는 이 티켓 파일에 절대 적지 마세요.

- [ ] `.env`에 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`, `KAKAO_REST_API_KEY` 세 개가 채워짐
- [ ] 네이버 일일 허용량 실제 숫자: ______
- [ ] 카카오 쿼터(표시되는 경우): ______
- [ ] 두 API가 실제로 응답하는지 호출 확인 (키 받은 뒤 에이전트가 수행)
