## Question

지금은 전체 상위 20개를 뽑고 부문은 라벨일 뿐이라, 부문을 누르면 그 안에 2~4개밖에 없다.
부문마다 20개를 채우려면 후보 풀이 훨씬 커야 한다.

제약: GitHub `core` 는 무인증 시간당 60회다. 부문 12개 × 20개 = 240개 레포의
주간 증가분을 매일 구하려면 **토큰이 사실상 필수**다 ([11](11-cloudflare-setup.md)).
토큰이 없으면 부문별 개수를 줄이고 그 사실을 화면에 밝힌다.
