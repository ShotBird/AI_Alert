# 13. AI 커뮤니티 Top5 — 트래픽이 모이는 곳

Type: task
Status: claimed
Blocked by: (없음)

## Question

사용자 요청: "AI 관련 트래픽이 가장 많이 모이는 탑 커뮤니티 Top5. Threads나 Reddit처럼
허가 없이 불러올 수 없는 사이트라도 트래픽이 얼마나 모이는지는 분석할 수 있지 않나?"

**부분적으로 가능하고, 무엇이 가능한지 정확히 구분해야 한다.**

### 가능한 것

1. **전체 트래픽 순위** — Tranco 가 무료·무인증으로 도메인 순위를 준다. 실제 호출해 확인했다.
   `GET https://tranco-list.eu/api/ranks/domain/threads.com` → `rank: 615`,
   `dcinside.com` → `rank: 1205`.
   CrUX·Cloudflare Radar·Majestic·Umbrella 를 합산한 학술용 목록이라 출처도 깨끗하다.
   **연속 호출에 429 를 주므로** 속도를 늦추고 캐시해야 한다 (순위는 하루에 1 정도만 움직인다).

2. **화제 유입량** — 우리가 이미 모은 항목들이 어느 도메인을 가리키는지 세면 된다.
   추가 수집이 0건이고, 이게 **AI에 한정된 유일한 신호**다.

### 불가능한 것 — 그리고 이게 중요하다

**`reddit.com` 의 순위는 레딧 전체의 것이지 r/LocalLLaMA 의 것이 아니다.**
사이트 안에서 AI 대화가 차지하는 비중은 그 사이트의 API 로만 알 수 있고,
Reddit 은 승인제, Threads 는 타인 글 읽기 자체가 불가, 디시인사이드는 약관이 금지한다.
즉 **"AI 트래픽 Top5"는 만들 수 없고, 두 가지를 나란히 보여주는 것까지가 정직한 최대치다.**

그래서 섹션을 이렇게 정의한다:

> **AI 커뮤니티 Top5** — 오늘 AI 화제가 어디로 흘러갔나(우리 측정) + 그 사이트의 전체 규모(Tranco)

두 숫자의 성격이 다르다는 것을 화면에서도 숨기지 않는다.
