# 06. GitHub 스킬 부문 택소노미 확정

Type: grilling
Status: open
Blocked by: (없음)

## Question

"디자인·백엔드·프론트엔드·계획 등 부문별 랭킹"을 원하셨는데, **GitHub에는 그런 분류 필드가 없다.**
`topic:claude-skills` 태그에 8,726개 레포가 있지만 태그는 자유 문자열이고 일관성이 없다.
따라서 부문은 **우리가 정의하고 LLM이 설명문을 읽어 분류**해야 한다.

정해야 할 것:

- 부문 목록을 확정한다. 초안: 디자인 / 프론트엔드 / 백엔드 / 계획·기획 / 데이터·분석 / 문서·글쓰기 / 기타
  — 너무 잘게 쪼개면 부문마다 한두 개씩만 남아 랭킹이 무의미해진다
- **"핫하다"의 기준**: 누적 스타 수인가, 최근 7일 스타 증가분인가, 신규 생성인가?
  누적으로 하면 같은 레포가 몇 달 내내 1등이라 매일 볼 이유가 없어진다
- 분류가 애매한 레포(여러 부문에 걸침)를 어떻게 처리하는가
- 분류 결과를 캐시하는가 — 같은 레포를 매일 다시 분류하면 돈과 시간이 낭비된다

`grilling` + `domain-modeling` 스킬을 호출할 것.
