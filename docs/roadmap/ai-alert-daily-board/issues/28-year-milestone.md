## Question

사용자 요청: 모델 업데이트 **위쪽에 1년 기준 마일스톤**을 작고 심플하게.
1월 1일 ~ 12월 31일 축. 마일스톤에는 **(월/일) + LLM 모델명만**. 현재·예정 표기.
**마일스톤에만 '과거' 모델 업데이트 이력을 추가**한다.

### 왜 마일스톤만 과거를 갖는가

현황판은 "지금 최신이 무엇인가"를 답한다 — 계열마다 한 줄, 최신 하나.
마일스톤은 다른 질문에 답한다: **"올해 이 판이 어떻게 흘러왔나."**
그래서 같은 데이터를 쓰되 마일스톤만 연중 이력을 편다.

### 데이터

추가 수집 없이 이미 닿는 곳에서 모은다:

- **Hugging Face**: `api/models?author=X&sort=createdAt` 으로 회사별 과거 목록.
  계열+버전 판정([19](19-model-families.md))을 그대로 써서 실제 모델만 남긴다
- **벤더 페이지**: x.ai 는 75건이 날짜와 함께 나온다
- **수집한 피드**: 올해 안의 출시 항목

올해(1/1~오늘) 것만 싣고, 같은 날 같은 계열은 하나로 합친다.
**모델명만 적는다** — 제목 전체를 실으면 축이 글자로 덮인다.
