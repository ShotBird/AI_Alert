## Question

사용자 요청: **해외 뉴스는 기본을 한국어 번역으로 보여주고, 원문은 버튼으로.** 번역은 LLM.

### 앞선 결정을 뒤집는다

[05](05-daily-board-schema.md)에서 "원문 제목 그대로 + 아래 한국어 요약"으로 정했다.
근거는 고유명사가 번역되면 검색이 안 된다는 것이었다. 사용자가 써보고 **한국어가 기본이어야
한다**고 판단했으므로 그쪽으로 바꾼다. 고유명사 문제는 **원문 버튼**으로 해결된다.

### 구현

- 카드에 `title_ko` 추가. 해외(`region == "global"`) 항목만
- 화면은 `title_ko` 를 제목 자리에 놓고, `원문` 버튼을 누르면 원문 제목이 펼쳐진다
- 번역은 `summarize.py` 가 맡는다. **키가 없으면 씨앗 캐시**(`state/news-notes.json`)를 쓰고,
  캐시에도 없으면 원문을 그대로 둔다 — 빈 제목보다 낫다

### 함께 고칠 것: 오늘의 키워드

두 단어 묶음을 넣었더니 `researchers used`, `CC agent` 같은 **문장 조각**이 올라온다.
빈도 기반의 한계가 그대로 드러난 것이다. 동사·기능어로 시작하거나 끝나는 조각을 버리고,
그래도 남는 게 없으면 **빈 섹션이 정직하다.** LLM 키가 붙으면 이 문제 자체가 사라진다.
