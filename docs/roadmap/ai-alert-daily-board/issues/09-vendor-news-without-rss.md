# 09. RSS 없는 벤더(Anthropic·xAI·Meta·DeepSeek)를 어떻게 잡을 것인가

Type: grilling
Status: resolved
Blocked by: (없음)

## Question

[01](01-verify-source-feeds.md)에서 확인된 것: **Anthropic, xAI, Meta, DeepSeek는 RSS가 아예 없다.**
추측이 아니라 원문 HTML에 자동발견 링크 태그가 없음을 확인했다.
그런데 이 넷이 빠지면 "주요 회사별 모델 업데이트"라는 기능의 절반이 사라진다.

선택지:

1. **Hugging Face API로 갈음** — Meta·DeepSeek는 가중치를 HF에 올리므로 잡힌다.
   Anthropic·xAI는 클로즈드라 **안 잡힌다**
2. **커뮤니티 미러 피드에 의존** — 누군가 GitHub Actions로 스크래핑해 만든 비공식 RSS가 존재한다.
   공짜지만 남의 취미 프로젝트가 멈추면 같이 멈춘다
3. **뉴스 섹션이 대신하게 둔다** — Anthropic이 뭘 내놓으면 TechCrunch·HN이 반드시 다룬다.
   즉 별도 벤더 추적을 포기하고, 뉴스에서 벤더명으로 필터링해 모델 업데이트 섹션을 만든다
4. **해당 벤더 뉴스 페이지를 직접 파싱** — robots.txt와 약관을 먼저 확인해야 한다

핵심 질문: **"모델 업데이트"는 공식 발표를 봐야 하는가, 아니면 "새 모델이 나왔다는 사실"만 알면 되는가?**
후자라면 3번이 가장 튼튼하고 공짜다.

`grilling` + `domain-modeling` 스킬을 호출할 것.

---

## Answer

> **에이전트가 대신 결정함** (2026-09-20 야간 자율 세션).

### 먼저 티켓의 핵심 질문에 답하면

> "공식 발표를 봐야 하는가, 새 모델이 나왔다는 사실만 알면 되는가?"

**사실을 아는 게 1순위, 공식 발표문은 확보되면 더 좋은 것**으로 정한다.
조사해보니 대부분의 경우 **둘 다 어렵지 않게 잡힌다.** 그래서 굳이 하나를 포기할 이유가 없었다.

### 결정 — 벤더마다 다르다

| 벤더 | 1차 채널 | 교차검증 | 상태 |
|---|---|---|---|
| **Anthropic** | 커뮤니티 미러 RSS | anthropic.com/news 직접 파싱 (폴백) | ✅ 해결 |
| **Meta** | ai.meta.com/blog 직접 파싱 | HF `meta-llama` 폴링 | ✅ 해결 |
| **DeepSeek** | HF `deepseek-ai` 폴링 | deepseek.com/en/news/ 파싱 + 뉴스 | ✅ 삼중 |
| **xAI** | x.ai/news 직접 파싱 + 재시도 | 없음 | ⚠️ **유일한 공백** |

### robots.txt를 전부 확인했다 — 네 곳 다 허용한다

| 도메인 | robots.txt | 페이지 |
|---|---|---|
| anthropic.com | `Allow: /` 전면 허용 | 서버렌더링, 정적 파싱 가능 |
| x.ai | `Allow: /`, `Disallow: /tools/`만. **`Content-Signal: ai-train=yes, ai-input=yes`** — AI 이용을 명시적으로 허용 | 서버렌더링이나 Cloudflare 봇챌린지가 간헐 발생 |
| ai.meta.com | 특정 봇만 차단(PetalBot·Scrapy·Yandex). AI 전용 UA 언급 없음 | 서버렌더링, 정적 파싱 가능 |
| deepseek.com | `Allow: /` 전면 허용 | 릴리스별 개별 페이지 존재 |

**디시인사이드와 정반대 상황이다.** 그쪽은 약관이 자동 수집을 명시적으로 금지했지만,
여기는 네 곳 다 막지 않고 x.ai는 오히려 AI 이용을 공식 허용한다. **그래서 직접 파싱이 1차 전략이 될 수 있다.**
x.ai의 간헐적 챌린지는 **차단이 아니라 불안정**이므로 일반적인 재시도·백오프로 대응한다.
회피 기법은 쓰지 않는다 — 필요도 없다.

### Anthropic 미러는 살아 있다

`taobojlen/anthropic-rss-feed`를 실제로 확인했다:
- 유효한 RSS 2.0, 13개 항목, **최신 항목이 2일 전**
- 모델 발표도 공식 제목 그대로 잡혀 있었다 ("Introducing Claude Fable 5.1 and Claude Mythos 5.1")
- 레포 `pushed_at`이 **오늘** — 지금도 자동으로 돌고 있다

"몇 달 방치된 미러"라는 우려는 기각됐다. 다만 **남의 개인 프로젝트라 단일 장애점**이므로,
죽으면 anthropic.com 직접 파싱으로 넘어간다(robots.txt가 허용한다).

### 뉴스로 대체하는 안이 왜 탈락했나 — 중요한 발견

원래 유력 후보였던 "뉴스 커버리지가 대신한다"는 **회사명으로 검색하면 무너진다.**

| 검색어 | 30일 건수 | 상위 내용 |
|---|---|---|
| "Anthropic" | 443건 | 상위 8개 **전부** 소송·사임·정치. **제품 발표 0건** |
| "Claude" | 805건 | **1위(1419점)가 모델 발표 그 자체** |
| "xAI" | 9건 | 전부 소송·정치. 제품 신호 0 |
| "Grok" | 511건 | 상위는 정전·소송. 실제 출시는 **1~4점에 묻혀** 어떤 임계값으로도 못 건짐 |
| "DeepSeek" | 107건 | **1위(1015점)가 릴리스**, 상위 8개 중 5개가 같은 건 |

**회사명은 드라마를 끌어오고, 제품명은 발표를 끌어온다.**
이건 09를 넘어 뉴스 섹션 전체에 적용되는 규칙이라 아래에 따로 남긴다.

### xAI만 남은 공백 — 얼마나 나쁜가

**심각하지 않다.** 막혀서 못 읽는 게 아니라 가끔 재시도가 필요한 정도다.
robots.txt는 허용하고, 페이지도 서버렌더링이라 내용이 읽힌다. Cloudflare 챌린지가 간헐적으로 뜰 뿐이다.
실패하면 [05](05-daily-board-schema.md)의 규칙대로 **정직하게 비워두고 이유를 적는다.**

참고로 **Meta가 17개월간 신규 Llama를 안 냈다**는 사실도 확인됐다. HF에도 없고 HN에도 없다.
이건 **수집 실패가 아니라 진짜 침묵**이다. 섹션이 비었을 때 우리 잘못인지 세상이 조용한 건지
구분할 수 있어야 한다는 뜻이다.

### 이 티켓이 뉴스 섹션에 남기는 규칙

**벤더 필터는 회사명이 아니라 제품명으로 건다.**
`Claude` · `Grok` · `Gemini` · `Llama` · `DeepSeek` · `GPT` · `Qwen` · `Mistral`
회사명(`Anthropic`, `xAI`, `OpenAI`)으로 걸면 소송·인사·정치 기사가 모델 업데이트 섹션을 채운다.
