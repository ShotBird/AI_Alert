# 04. 알림 채널 확정

Type: research
Status: resolved
Blocked by: (없음)

## Question

홈화면 웹앱(PWA)은 백그라운드 푸시가 약하다. 사용자가 정한 시각에 확실히 알림을 받으려면
메신저 봇을 함께 두는 편이 낫다. 어느 쪽인가?

비교할 것:

- **텔레그램 봇**: 만들기 가장 쉽다. 단 봇 약관이 *공개 채널 내용을 모아 제품을 만드는 것*을 금지한다 —
  **알림 발송 전용**으로만 쓰면 이 조항에 걸리지 않는지 확인할 것. 이게 핵심 질문이다.
- **카카오톡 "나에게 보내기"**: 한국 사용자에게 가장 자연스럽다.
  카카오 메시지 API의 개인 사용 조건, 토큰 갱신 주기(리프레시가 만료되면 사람이 다시 로그인해야 하는지),
  메시지 템플릿 제약을 확인할 것. **토큰이 주기적으로 끊기면 개인 프로젝트에서는 치명적이다.**
- **이메일**: 가장 지루하지만 가장 안 끊긴다. 발송 수단은 이미 있다(`send_mail.py`, Gmail SMTP).
- **PWA 웹 푸시**: 아이폰에서 홈화면 추가 후 사용자가 한 번 허용하면 가능하다고 알려져 있다.
  실제로 정해진 시각에 발송하려면 푸시 서버가 필요한데, 서버 없는 구조에서 가능한지 확인할 것.

해결 조건: 하나를 고르고, **왜 나머지를 버렸는지**와 **끊겼을 때 어떻게 아는지**를 적는다.

## Answer

**아이폰의 단축어(Shortcuts) 개인 자동화를 주 채널로 쓰고, 이메일을 "조용히 죽었는지" 감지하는 백업으로 둔다.**

결정적 이유: 사용자가 **시각을 직접 정하겠다**고 했는데, 단축어는 그 시각이 **아이폰 안의 시간 선택기**다.
서버도, 토큰도, 배포도 없이 사용자가 언제든 바꾼다. 다른 어떤 방식도 이 요구를 이만큼 싸게 만족시키지 못한다.

- 시간 트리거 자동화는 **"실행 전 확인"을 꺼서 조용히 실행**할 수 있고, 잠금 상태에서도 돈다 (Apple 공식 문서)
- 동작: `URL 콘텐츠 가져오기`(그날 JSON) → 값 추출 → `알림 표시`
- 설정은 6~10번 탭. 코드·계정·서버 없음

### 탈락 사유

- **텔레그램** — 약관 4.3은 *수집* 방향을 금지한다: "collect, store, aggregate or process data ... such as scraping public group or channel contents". 본인에게 보내기만 하는 발신 전용 봇은 이 조항 **밖**이다. 즉 약관은 문제없다. 다만 스케줄러가 돌아가는 서버가 여전히 필요해서, 이메일 대비 이득이 없다
- **카카오톡 나에게 보내기** — 비즈앱 전환 불필요, 발송 건수 제한 없음. 그러나 **액세스 토큰 6~12시간, 리프레시 토큰 60일**이고 갱신은 *잔여 30일 미만일 때만* 일어난다. 매일 돌면 무한 연장되지만, **다른 이유로 60일 이상 멈추면 토큰이 영구히 죽고 사용자가 브라우저로 재로그인**해야 한다. 이미 고장난 상황 위에 수동 복구 단계를 하나 더 쌓는 구조라 탈락
- **PWA 웹 푸시** — iOS 16.4+에서 가능하지만 홈화면 추가가 선행돼야 하고, 권한 요청이 사용자 탭으로만 가능하며, 예약 발송을 하려면 VAPID 키 + 구독 정보 저장소 + 정시에 깨는 프로세스가 필요하다. "서버 없음"이라는 전제와 정면으로 충돌하고 작업량이 4~16시간. 하루 한 통에 과하다
- **이메일 단독** — 가장 안 죽지만 배너 알림이 아니라 그냥 쌓인다. 그래서 주 채널이 아니라 백업

### 조용히 죽으면 어떻게 아는가

단축어 자동화는 **안 돌아도 아무도 안 알려준다.** 이게 이 선택의 유일한 약점이라 백업을 붙인다:
생성 잡이 매일 다이제스트를 **이메일로도 보낸다**(발송 스크립트는 이미 있다).
알림이 안 뜨는 건 눈치채기 어렵지만, **매일 오던 메일이 끊기는 건 눈치챈다.**

### 이 결정이 바꾸는 것

"설정 화면에서 생성/알림 시각 지정"이라는 앞선 가정이 흔들린다 — **알림 시각은 앱이 아니라 아이폰 단축어에 산다.**
앱 설정에 남는 건 섹션 on/off 정도다. 티켓 05·07·08에 반영할 것.
